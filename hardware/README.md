# Hardware

## PCB

Open `pcb/FlexSensor_BluetoothBoard/FlexSensor_BluetoothBoard.kicad_pro` with KiCad. The project directory contains the schematic, board file, project settings, and custom MXC4005XC footprint files under `pcb/KiCADv6`.

The supplied PCB file has no placed footprints, so the layout appears unfinished in this snapshot. The schematic and project files are present.

## Mechanical parts

The STL exports in `mechanical/` are retained with descriptive filenames. Their original source filenames did not identify the part geometry.
